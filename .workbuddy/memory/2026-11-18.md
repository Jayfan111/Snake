## 贪吃蛇项目：设计阶段结论

用户在写一个 Java 贪吃蛇，本日全部在讨论软件过程与架构，**尚未产出任何代码**（src 下三个包目录均为空）。

### 已确认的技术决策
- 语言/UI：**Java + Swing**（JPanel + javax.swing.Timer），不用 JavaFX / libGDX / Android。理由：零依赖，JDK 自带，ARM64 无坑。
- 构建工具：**不引入 Maven**。零第三方依赖，`javac` / IDEA 编译 + JDK 自带 `jar` 打包足够。将来需要 JUnit、第三方库或 CI 时再补 pom。
- 目录布局：`src/main/java` 作为唯一源码根（Maven 形状但无 pom，保留以便将来零成本迁移）。
- 环境：IDEA 项目 Snake，JDK = **liberica-26**（ARM64），语言级别 21，无模块系统。

### 包结构与职责（已达成一致）
- `model`：Cell(record) / Direction(enum) / Snake / Board / GameModel / GameState(enum)
- `loop`：Main（装配启动）/ GameLoop（Timer 与跨层调度）
- `view`：GamePanel（paintComponent）/ InputHandler（按键→意图翻译）

核心规则：model 不 import awt/swing、不持 Timer；view 只读 model；loop 是唯一同时认识两边者。
架构定位：不是标准 MVC（无 Observer 推送），是 **Model-View-Loop（拉取式）**，接近 MVP 变体。
